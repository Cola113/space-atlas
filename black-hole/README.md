# 临界 · 黑洞观测站

Space Atlas 的沉浸式黑洞场景。使用 **Vite + TypeScript + Three.js WebGLRenderer + WebGL2 + GLSL 3**，原生 HTML/CSS 界面，黑洞渲染无需后端服务。核心通过 GPU 数值积分弯曲光线，同时采样吸积盘和背景星空。

## 直接体验

访问统一站点下的 `/black-hole/`，也可以在左上角的场景菜单切换到黑洞。

环境要求：Node.js 22.12+，支持 WebGL2 的现代浏览器，建议开启硬件加速。

```sh
npm ci
npm run build
npm run preview
```

以上命令都在仓库根目录执行。地址以终端输出为准；正式服务运行 `npm start`。统一构建面向域名根路径，网页需要通过 HTTP 访问，不能直接双击 HTML。

## 观察方式

| 操作 | 效果 |
| --- | --- |
| 鼠标拖动 / 单指拖动 | 围绕黑洞连续旋转 |
| 滚轮 / 双指缩放 / ＋− | 沿当前观察方向连续靠近或远离，保持固定 45° 垂直视场 |
| 点击可见吸积盘 | 根据 GPU 交点进入对应盘面细节视角 |
| 点击高阶盘面影像 | 进入侧面观察；拾取使用与可见画面相同的光线积分 |
| 整体 / 侧面 / 盘面 / 俯瞰 | 平滑加减速镜头过渡，连续操作从实际位置接续 |
| 自动巡游 | 自由镜头的连续轨道运动；触碰画面或滚轮可立即接管 |
| 暂停 / 恢复 | 冻结盘面与巡游时间，仍然允许手动观察 |
| 倍速 | 0.25、0.5、1、2、4 倍演示时间 |
| 相机按钮 | 保存当前无界面 PNG，最大长边 4096 像素 |
| 设置 → 影像记录 | 指定时间，导出横屏或竖屏固定全景 |
| 空格 / C / R / 1–4 | 暂停、巡游、全景和预设视角 |

默认关闭说明面板，无天体名称标牌或辅助线。桌面保留底部工具栏与角落状态，手机采用独立全景距离、紧凑工具栏、可滚动面板及安全区间距。展开侧面板时收起可能被挡住的缩放按钮，底部工具栏仍可操作。

观察限制：轨道距离为 14.5–140 Rₛ，镜头目标偏移最多 2.3 Rₛ；俯仰限于盘面上方约 2.6°–85.4°。镜头始终位于盘外，第一版不穿越视界或穿过理想薄盘。

## 科学模型与边界

采用无自旋、无电荷的 Schwarzschild 时空，所有长度以 `Rₛ = 2GM/c²` 归一化。事件视界为 1 Rₛ，光子球为 1.5 Rₛ，稳定薄盘从 3 Rₛ 开始，展示外边界为 9 Rₛ。远场阴影临界冲击参数为 `√27 / 2 ≈ 2.598076 Rₛ`；这不是事件视界或某个实体球面的半径。薄盘发光会覆盖部分捕获光线对应的区域。

GPU 对 `u″ = 1.5u² − u`（`u = Rₛ/r`）使用四阶 Runge–Kutta 积分。初始方向在静止观察者的局部正交标架中定义，`b = r₀ sin α / √(1−1/r₀)`，`u′₀ = −cos α / b`。盘面相交角度解析计算，积分准确推进到交点；逸出光线的渐近方向用于采样同一张星空贴图。阴影、盘面弧和有限高阶环来自这一过程，没有叠加固定黑圆或二维弯曲贴片。

为限制实时开销，最多跟踪约 `4π` 方位角，极端高阶未决光线作吸收处理。GPU 真空诊断使用同一积分器，临界值与解析值的实际误差见 [验证报告](verification/VALIDATION.md)。这是实时近似，并非科研级无限精度积分。

吸积盘的圆轨道速度采用 `β = 1 / √[2(r−1)]`，以引力红移和近似多普勒因子计算 `g³` 比强度权重。颜色采用金白至橙红的艺术映射；不是特定波段的黑体光谱测量。盘面采用理想薄盘、有限不透明度与程序化湍流，局部亮斑和条带用于展示物质流动，不是 GRMHD 解。没有自旋、喷流、光行时差、完整辐射转移、观察者相对论运动像差或实测天体质量，因此不提供质量、自旋滑块。

流动使用两个错开 24 秒、寿命 48 秒的有限剪切场，以平滑权重交接；大时间先在 JavaScript 双精度中取周期，再传入 GPU，避免浮点精度丢失和无限拉伸。所有动画以演示秒计时，不能当作某一实测黑洞的物理时间。两种时间周期共同在 240 秒后精确重复，便于稳定长时播放。

星空为固定种子 1787 生成的合成球面贴图，不是观测星表。它参与引力透镜，但星点有有限角尺寸；临界曲线和高倍率视角附近可能拉长或闪烁。第一版没有实现 Bruneton 的完整点星光束过滤或预计算查表，只采用其模型方程与几何关系进行直接积分。辉光为显示效果，独立于物理高阶影像。

科学参考（核对于 2026-09-08）：

- [NASA：Black Hole’s Warped World](https://www.nasa.gov/universe/nasa-visualization-shows-a-black-holes-warped-world/) — 盘面扭曲影像、多普勒增亮、阴影与视界的区别。
- [Eric Bruneton (2020)：Real-time High-Quality Rendering of Non-Rotating Black Holes](https://arxiv.org/abs/2010.08735) — Schwarzschild 光线方程及薄盘相交关系，尤其原论文式 8。代码为本项目独立实现，未声称实现论文的完整渲染算法。
- [Narayan, Johnson & Gammie (2019)：The Shadow of a Spherically Accreting Black Hole](https://arxiv.org/abs/1910.02957) — 阴影临界尺度 `√27 r_g`，其中 `r_g = Rₛ/2`。

## 架构

| 模块 | 职责 |
| --- | --- |
| `src/app/Observatory.ts` | 初始化、唯一 RAF、生命周期、事件协调、公开接口与释放 |
| `src/rendering/Pipeline.ts` | WebGLRenderer、线性 HDR 渲染、GPU 拾取、后期及纹理资源 |
| `src/shaders/` | 零测地线、盘面、星空、辉光、FXAA 与显示转换 |
| `src/simulation/` | 模型常量、周期相位、暂停/倍速/后台恢复时间系统 |
| `src/camera/CameraRig.ts` | OrbitControls、平滑缩放、镜头过渡与巡游 |
| `src/ui/` | 原生界面、状态差量更新、响应式布局和无障碍操作 |
| `src/quality/Quality.ts` | 能力检测、画质配置、FPS 监测、迟滞策略 |
| `src/capture/Capture.ts` | 同一渲染管线的指定时间 PNG，恢复实时状态 |

渲染路径：线性 HDR 场景 → 四分之一边长的辉光 → FXAA / 一次 ACES 曲线 → 一次 sRGB 编码。Three.js 的重复色调映射关闭，无透明几何体排序问题。没有浮点渲染附件时使用 8 位附件兼容模式，动态范围会降低。着色器在首帧前预编译；上下文丢失时清理旧 GPU 句柄，恢复后重新建立资源。

| 画质 | 内部比例 | DPR 上限 | 步数上限 | 角步长 | 辉光 |
| --- | ---: | ---: | ---: | ---: | --- |
| 节能 | 0.65 | 1 | 224 | 0.061 | 关闭 |
| 均衡 | 0.82 | 1.25 | 320 | 0.043 | 开启 |
| 精细 | 1 | 1.5 | 448 | 0.030 | 开启 |
| 极致 | 1 | 2 | 640 | 0.0215 | 开启 |

多数光线会提前逸出或被吸收，实际迭代数低于上限。桌面自动从精细开始，移动端从均衡开始。每 2.5 秒汇总一次帧时，连续 3 个低帧率窗口才降低画质，连续 8 个高帧率窗口才提升；调整之间至少间隔 15 秒。自动模式不升至极致，移动端不自动超过均衡。手动画质锁定，截图画质显式指定。

后台不累计隐藏期间的时间，恢复后首帧重置时间基准，意外长间隔最多计入 50 ms。UI 文本仅在状态变化时刷新，性能读数每 500 ms 才检查；没有逐帧布局测量。

## 可重复采样与影片基础

页面加载完成后可使用 `window.observatory`：

```js
const frame = window.observatory.renderAt({
  time: 24,
  width: 1920,
  height: 1080,
  preset: 'overview', // overview | edge | disk | top
  quality: 'high',   // low | medium | high | ultra
});
// frame.dataUrl: PNG；frame.hash: 像素 FNV-1a；另含像素统计和相机参数。
```

支持 `0 ≤ time ≤ 1e12`，宽高为 64–4096 的整数。可传 `camera: { radius, polar, azimuth, target: [x,y,z] }` 制作自己的连续镜头；半径、极角与方位角均遵循 Three.js Spherical 约定，角度为弧度，距离为 Rₛ。目标离原点不得超过 2.5 Rₛ。省略相机时横竖屏预设分别取景。采样不修改实时相机、暂停状态、总时间和画质设置。

后续用 Playwright 在循环中传入 `time: frameIndex / fps`，保存 `dataUrl` 即可得到确定性 PNG 序列；同一视角下使用同一参数轨迹，横屏和竖屏共用模拟。`getState()` 可读取诊断数据，`setTime()`、`setPaused()`、`setView()`、`setQuality()` 可控制观测状态。

固定画幅的常规重复采样已验证字节一致；频繁交替画质与尺寸的压力测试还会检查实际像素差异。GPU 的末位量化可能使极少像素的哈希不同，因此不能保证所有组合、浏览器与驱动始终逐字节一致；实际差异与验收阈值保存在验证报告中。不包含编码器、音频或影片剪辑功能。

## 验证与素材

```sh
npm test                   # 物理关系、时间与画质迟滞
npm run test:browser       # Playwright：功能、截图与持续运行
```

集成测试默认使用 Microsoft Edge（`channel: 'msedge'`）。可通过 `ATLAS_URL` 指向待测试站点，截图和结果输出到根目录的 `test-results/`。手机输入和视口模拟不等于实体手机续航或热稳定性测试，Safari/iOS 尚未实机验证。

全部运行素材随项目保存。共享星空 `public/shared/starfield.png` 可通过根目录的 `node scripts/generate-stars.mjs` 重建，是固定种子的原创合成纹理。图标来自 Lucide（ISC），Three.js 和 Vite 采用 MIT 许可；许可证在根目录的 `public/licenses/`。
