# 天王星环带 · 2026-09-25

接续「看一下天王星的环带，目前非常不明显且有一条黑线，怎么变得美观艺术一点？」会话。
原会话停在初步着色器调整，尚未完成视觉验收。本轮完成银蓝细环显示、近环平面连续性和说明标注。

## 修改范围

- `solar-system/src/ring-display.js`：显式的天王星艺术显示；稠密窄环提高可见覆盖率，冷银蓝调色、柔和补光、半透明前景。
- `dynamics.js`：环的最小栅格宽度按投影切线法向求解；真实半径、半宽和相邻间隙上界继续读取原几何。
- `ring-photometry.js`：复用同一显示函数，默认土星增强权重为零；没有复制或替换物理散射解。
- `data.js` 与 `BODY_MODELS.md`：用户可见的艺术增强标注及准确范围。环的屏幕光度和颜色不作为实测值。

所有环继续用同一份 GLSL 程序，由材质 uniform 选择增强，避免按天体拼接不同代码却复用同一着色器缓存键的问题。
没有生成贴图，没有更改轨道、日期、姿态、环区数据或散射表。

## 复现

启动开发服务 `npm run dev -- --port 5199`。`capture.mjs` 固定日期为 2026-09-25 12:00 UTC（2026-09-25 20:00 北京时间）。

```powershell
$env:LABEL='final'
node outputs/uranus-rings-20260925/capture.mjs
$env:LABEL='physical'
$env:BASELINE='1'
$env:ONLY='edge'
node outputs/uranus-rings-20260925/capture.mjs
Remove-Item Env:BASELINE,Env:ONLY
node outputs/uranus-rings-20260925/measure.mjs
```

默认视角始终截图，`ONLY` 仅限制后续视角。基线通过浏览器拦截 `ring-display.js` 将增强权重设为零，不修改工作区；只适用于开发服务。
`comparison.png` 左为无增强、右为最终增强，同一时间、姿态和镜头。
