# 土星云带的可见动态（2026-09-19）

## 问题

《星际图鉴》里木星的云带会明显流动（差速云带、大红斑周边云纹旋转），土星看起来几乎不动。
两者共用同一段云带漂移（`solar-system/src/dynamics.js` 的 `gasMap()`），为什么土星看不出来？

## 结论：共享漂移对土星不可见，因为贴图沿经度几乎没有结构

漂移层做的是**位移贴图取样坐标**。位移一个沿经度均匀的贴图，等于没有位移。

量测（`public/solar-system/textures/2k_saturn.jpg` 与 `2k_jupiter.jpg`，逐行沿经度求标准差，再对 128×64 重采样）：

| 贴图 | 沿经度起伏（行内标准差均值） | 沿纬度起伏（列内标准差均值） |
| --- | --- | --- |
| 土星 | **2.2** | 24.8 |
| 木星 | **6.9** | 25.4 |

土星贴图是一圈圈几乎纯纬向的平滑带纹（木星的三分之一），没有斑点、涡旋和细丝；木星的大红斑与涡旋在经度上留下的结构正是"看得见在动"的来源。实拍画面本身也没有问题——Cassini 影像里的土星就是这样，问题在展示层需要**自己生成可被眼睛追踪的结构**。

## 改动（`gasMap()` 的 saturn 分支）

1. 云带差速漂移加快：`drift` 0.001 → 0.003（土星实测急流快于木星，量级为展示取值）。
2. 新增**程序云絮层**：沿经度拉长、只在纬向剪切带最强的细云絮，由同一套带内急流速度推动，所以相邻云带之间会互相剪切错动。
3. 新增**两个亮斑**（带暗色包边与噪声破碎的斑心），沿各自纬度以不同速度漂移，给眼睛一个可追踪的参照——对应木星上大红斑扮演的角色。
4. 活动事件期间在风暴中心生成白斑（复用 `stormCloud`）。

位置、形态、寿命与漂移速度均为**展示近似**，不对应任何一次观测；土星的大白斑是罕见事件，不能安上固定时刻。

## 验收数字（同一取景、8 帧、约 6.2 秒、`speed=500`）

判据：圆面内相邻帧之间亮度变化超过 8/255 的像素比例（`scripts/capture-atmosphere.mjs` 输出）。

| 状态 | 首末帧 | 相邻帧 |
| --- | --- | --- |
| 修改前 | 0.8% | 0.7% |
| 修改后 | 17.4% | 7.0% |

其它型号/取景下的数字会变；这组数字只说明"动起来了"，不代表物理风速。

## 复现

```bash
npm run build
NODE_PATH=$PWD/node_modules node scripts/capture-atmosphere.mjs saturn test-results/atmosphere 8 700 1
```

脚本在 `test-results/<目录>` 留下连续帧和一个 `saturn-motion.json`（含每帧状态与变化比例），
截图不进仓库（`outputs/**/*.png` 与 `test-results/` 均被忽略）。
