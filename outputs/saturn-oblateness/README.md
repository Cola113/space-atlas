# 土星扁平率对比

用于判断「给土星加上扁平率」在视觉上值不值得做。**未修改主应用任何文件**，土星的 `shape: [1, 0.902, 1]` 只在本页内存里生效。

## 运行

```bash
npm run dev
# 打开 http://127.0.0.1:5173/outputs/saturn-oblateness/index.html
```

## 页面上能看到什么

左右并排两个土星，共用同一相机、光照与真实贴图（`2k_saturn.jpg`、`2k_saturn_ring_alpha.png`），
左边是当前实现（未配置 `shape`，`body-geometry.js` 回退为单位球），右边是加扁平率后的扁球。

- **绿色参考圆**是理想球体轮廓。左图上它与轮廓完全重合；右图上它在两极明显露出缺口——这就是压扁量。
- **视距倍率 1.00×** 按 1280×720 视口下应用默认取景的真实像素尺寸渲染，球体直径 172 px，
  用来判断「实际看的时候明不明显」。
- **环面张开角**是本页唯一影响可见程度的几何量。0° 为环侧视（正对赤道，压扁最明显），
  90° 为正对极轴（看到的是正圆赤道，完全看不出）。应用默认视图实测约 33°。

所有尺寸数字由渲染结果的 alpha 通道实测（渲染时临时隐藏环与参考线，只保留球体本体），
不是按公式估算。

## 实测结论

| 场景 | 赤道直径 | 极直径 | 压扁量 |
|---|---|---|---|
| 单位球（现状） | 173 px | 173 px | 0.0% |
| 扁球 · 默认视角 33° · 真实大小 | 173 px | 162 px | 6.6% |
| 扁球 · 默认视角 33° · 放大 2.74× | 492 px | 459 px | 6.8% |
| 扁球 · 环侧视 1° · 放大 2.74× | 493 px | 445 px | 9.8% |

9.8% 是理论上限（NASA 实测 120,536 / 108,728 km = 0.902）。应用默认视角约 33°，落在 6.6%–6.8%。

## 若决定落地到主应用

`shape: [1, 0.902, 1]` 加在 `solar-system/src/data.js` 的土星条目即可，`body-geometry.js` 已支持，
Y 轴正好是极轴且赤道半径不变，环的位置不受影响。但还需要一并处理：

- `solar-system/src/landmarks.js:121` 的锚点用 `uvDirection(uv).multiplyScalar(1.017)`，
  北极六边形在 90°N 且无 `shape` 感知，会浮在云顶上方；同文件 281 行的遮挡判断用标量 `body.radius`。
- 环影目前按单位球计算，压扁后需重新核对几何。
