# 候选落点天空几何复算

2026-09-15。对应 [TODO](../../TODO.md)「后续地表落点候选」。这里只做只读复算：用项目自己的星历与
IAU 姿态模型算候选落点的主星高度角、视直径、太阳高度角与环面张开角，**没有修改应用**。

起因是待办里两条候选的原始前提与几何不符（见下「更正」）。同一套计算也能用来在动工前筛落点和日期，
避免把只在某个纬度成立的观感当成全表面成立。

## 怎么跑

```bash
npx tsx outputs/landing-candidates/candidate-sky.mjs
```

脚本按需读取 `public/ephemeris/` 下的土星、天王星、冥王星年表；其余天体用随应用发布的内置星历。
全程只读，不启动浏览器。

## 方法

- 观察者位置与地平坐标取 `solar-system/src/surface/geometry.js` 的 `surfaceFrame` 与 `horizonAngles`，
  与降落视图用的是同一份代码、同一模拟时刻，因此这里算出的天空就是用户实际会看到的天空。
- 「主星高度角」指主星圆面中心的高度角；「视直径」用 `2·asin(R/d)`，与地表资料卡同一公式。
- 环面张开角取观察者到土星连线与土星自转轴的夹角，正号表示北面转向观察者，方向与地球上的记法一致。
- 采样窗口写在每节标题里：一般为一个自转周期，月球用朔望月以包含天平动，环面张开角每历元覆盖一个
  79.33 天轨道周期。
- 「次主星经度」由经度扫描得到。同步自转的卫星上主星位置固定，因此主星高度角最高处就是朝主星点；
  潮汐锁定天体上这个点是固定的地面位置，不是每天经过的方向。

## 更正

### 优先 1 · 火卫一

原设「斯蒂克尼坑附近 + 天空中的巨大火星」在本项目的姿态模型里取不到同一个位置。

| 位置 | 火星高度角（一个轨道周期） | 火星视直径 |
| --- | --- | --- |
| 次火星点，约 60°E | 84.7° – 89.8° | 41.8° – 43.1° |
| 约 150°E | −5.2° – +0.6° | 41.7° – 43.1° |
| 斯蒂克尼坑 1°N / 49°W | −19.7° – −14.0° | 41.7° – 43.1° |

火星视直径全表面都在 41.7°–43.1° 之间，原估的约 42° 成立；但次火星点位于东经约 60°，
斯蒂克尼坑（311°E）距该点约 109°，火星在那里始终在地平线下 ≈15°–20°。

火卫一本初子午线由 IAU 动力学定义，见
[WGCCRE 2015 更正](https://elib.dlr.de/132218/1/Archinal2019_Article_CorrectionToReportOfTheIAUWork.pdf)；
当前姿态模型不含物理天平动，因此上述经度在制作前仍须与贴图经线对齐复核。

### 优先 4 · 土卫八

原设「选择可见土星且环面有合适张开角的日期和位置」需要补两个限制。

| 项 | 复算结果 |
| --- | --- |
| 土星最高点 | 东经约 210°，高度角 83.4° – 88.5°，视直径 1.8° – 1.9° |
| 本初子午线 0°E 处 | 土星高度角 −54°（地平线下） |
| 环面张开角 | 一个轨道周期内 −14.0° – +14.0° |

土卫八轨道对土星赤道面倾斜 15.5°，这是张开角的来源；其余可降落土星卫星几乎就在环面内公转，
总是接近侧视（现有土卫二落点即是此情形）。受光与张开角相位的相对关系随约 29.5 年的土星季节改变：

| 历元 | 受光采样 | 受光时的张开角 |
| --- | --- | --- |
| 2026-09-15 | 46/97 | −14.0° – +13.7° |
| 2033-01-01 | 46/97 | 0.0° – +14.0° |
| 2040-01-01 | 46/97 | −12.9° – +14.0° |
| 2050-01-01 | 46/97 | −14.0° – +1.7° |

2050 历元受光时张开角最大只有 +1.7°，等于白昼全是侧视。日期须先从历元筛。
