# 候选落点天空几何复算

2026-09-15。对应 [TODO](../../TODO.md)「后续地表落点候选」。这里只做只读复算：用项目自己的星历与
IAU 姿态模型算候选落点的主星高度角、视直径、太阳高度角与环面张开角，**没有修改应用**。

起因是待办里两条候选的原始前提与几何不符（见下「更正」）。同一套计算也能用来在动工前筛落点和日期，
避免把只在某个纬度成立的观感当成全表面成立。

## 怎么跑

```bash
npx tsx outputs/landing-candidates/candidate-sky.mjs
```

脚本按需读取 `public/ephemeris/` 下的土星、天王星、冥王星年表；其余天体用随应用发布的内置星历。
全程只读，不启动浏览器。

## 方法

- 观察者位置与地平坐标取 `solar-system/src/surface/geometry.js` 的 `surfaceFrame` 与 `horizonAngles`，
  与降落视图用的是同一份代码、同一模拟时刻，因此这里算出的天空就是用户实际会看到的天空。
- 「主星高度角」指主星圆面中心的高度角；「视直径」用 `2·asin(R/d)`，与地表资料卡同一公式。
- 环面张开角取观察者到土星连线与土星自转轴的夹角，正号表示北面转向观察者，方向与地球上的记法一致。
- 采样窗口写在每节标题里：一般为一个自转周期，月球用朔望月以包含天平动，环面张开角每历元覆盖一个
  79.33 天轨道周期。
- 「次主星经度」由经度扫描得到。同步自转的卫星上主星位置固定，因此主星高度角最高处就是朝主星点；
  潮汐锁定天体上这个点是固定的地面位置，不是每天经过的方向。

## 更正

### 优先 1 · 火卫一

原设「斯蒂克尼坑附近 + 天空中的巨大火星」在本项目的姿态模型里取不到同一个位置。

| 位置 | 火星高度角（一个轨道周期） | 火星视直径 |
| --- | --- | --- |
| 次火星点，约 60°E | 84.7° – 89.8° | 41.8° – 43.1° |
| 约 150°E | −5.2° – +0.6° | 41.7° – 43.1° |
| 斯蒂克尼坑 1°N / 49°W | −19.7° – −14.0° | 41.7° – 43.1° |

火星视直径全表面都在 41.7°–43.1° 之间，原估的约 42° 成立；但次火星点位于东经约 60°，
斯蒂克尼坑（311°E）距该点约 109°，火星在那里始终在地平线下 ≈15°–20°。

火卫一本初子午线由 IAU 动力学定义，见
[WGCCRE 2015 更正](https://elib.dlr.de/132218/1/Archinal2019_Article_CorrectionToReportOfTheIAUWork.pdf)；
当前姿态模型不含物理天平动，因此上述经度在制作前仍须与贴图经线对齐复核。

### 优先 4 · 土卫八

原设「选择可见土星且环面有合适张开角的日期和位置」需要补两个限制。

| 项 | 复算结果 |
| --- | --- |
| 土星最高点 | 东经约 210°，高度角 83.4° – 88.5°，视直径 1.8° – 1.9° |
| 本初子午线 0°E 处 | 土星高度角 −54°（地平线下） |
| 环面张开角 | 一个轨道周期内 −14.0° – +14.0° |

土卫八轨道对土星赤道面倾斜 15.5°，这是张开角的来源；其余可降落土星卫星几乎就在环面内公转，
总是接近侧视（现有土卫二落点即是此情形）。受光与张开角相位的相对关系随约 29.5 年的土星季节改变：

| 历元 | 受光采样 | 受光时的张开角 |
| --- | --- | --- |
| 2026-09-15 | 46/97 | −14.0° – +13.7° |
| 2033-01-01 | 46/97 | 0.0° – +14.0° |
| 2040-01-01 | 46/97 | −12.9° – +14.0° |
| 2050-01-01 | 46/97 | −14.0° – +1.7° |

2050 历元受光时张开角最大只有 +1.7°，等于白昼全是侧视。日期须先从历元筛。

## 2026-09-16 落点实施时的复算脚本

新增七处落点时，下面三个脚本回答了"这处落点站上去会看到什么、够不够亮"：

| 脚本 | 做什么 |
| --- | --- |
| `check-default-light.mjs` | 每个落点在自身默认时刻的太阳高度、主星高度与视直径，用来确认到站时地面是亮的 |
| `pick-site-dates.mjs` | 在一个自转周期内找出太阳接近 22° 的时刻，作为默认资料时刻的候选 |
| `check-eclipses.mjs` | 每个落点默认时刻与整个周期内的主星遮挡比例，用来发现"太阳最高时正好被主星挡住" |

最后一个脚本查出两个真问题：次木星点上太阳每次经过天顶都会被木星遮挡（周期性日食，
一个公转周期一次），而「寻找日照」原先按"太阳最高"跳转，恰好跳进日食。现在日照搜索会
跳过被主星遮挡的时刻，相关断言在 `landing-expansion.test.js`，见
[表面观景来源](../../public/surface/README.md#2026-09-16-同日天体第二落点与冥卫一)。

## 2026-09-18 谷神星：先决条件是轨道本身

谷神星在待办里的四个候选中是唯一不需要先做价值取向取舍的一个（"没有天空几何问题"），
但开工后发现它另有一道门：**本项目原来把谷神星当作固定平均椭圆天体**，与另外 38 个小天体同列。
落点天空的第一项要求是太阳方向与独立星历一致（`ground-audit.test.js` 的门槛是 1 角分），
平均椭圆过不了这道门。

用 Horizons 的日心 J2000 位置量它（`ceres-horizons-vectors.json` 保留这组参考）：

| 日期 | 位置误差 | 太阳方向差 |
| --- | ---: | ---: |
| 1900-01-01 | 6754 万 km | 546.76′ |
| 1950-06-15 | 4470 万 km | 366.51′ |
| 1971-08-01 | 3606 万 km | 310.96′ |
| 2000-01-01 | 1330 万 km | 119.71′ |
| 2026-09-18（默认日期） | 3756 km | 0.03′ |
| 2050-01-01 | 1322 万 km | 115.82′ |
| 2100-12-31 | 4791 万 km | 429.58′ |

默认日期附近没问题，是因为 SBDB 的密切元素历元就在 2026-09；一离开历元，误差就按万公里增长。
其余三个候选（火卫一、海卫一、土卫八）走的是同一条平均椭圆路径，所以这条实测不只是谷神星的门槛——
它把"提高精度"那一项从附带改善变成了这几个落点共同的前置条件。

解法与结果：`scripts/build-small-body-ephemeris.py` 从 Horizons 取谷神星的 SPK（覆盖 1899-12 至 2101-01），
由 CSPICE 采样后按 NAIF 小行星星历同样的 32 天窗口、19 阶 Chebyshev 重表达，发布 201 个年份包（1.21 MiB）。
换的是表示而不是轨道解：逐窗记录源残差，最大 0.000063 km。接入后落点天空的太阳方向差为 0.0001 角分。

`ceres-okato.mjs` 复算落点几何：太阳高度角在一个 9.0742 小时的自转周期内 −73.35° 至 +67.24°，
太阳视直径 0.199°（地球所见的 0.37 倍），除太阳外没有可分辨天体。默认资料时刻取太阳高度角约 21.7°。

配套的两个探针脚本（量平均椭圆误差与位置的那对）用完即删：它们测的就是被替换掉的路径，
留在仓库里只会指向一个不再存在的模型。上表数值保留在本文与 `ceres-horizons-vectors.json` 中。

## 2026-09-25 地球 · 冒纳凯阿：先决条件是月亮高度

地球的第一个地表落点选作「赏月」观景点。候选依据（纬度决定月亮中天高度、海拔与暗空决定通透）
见 PR 讨论；本节记录动工前用项目星历做的月亮几何复算，脚本 `earth-maunakea.mjs`
（未登记落点前用同一套 `surfaceFrame` 直接计算，登记后 `landingSites.earth` 与之一致）。

落点取冒纳凯阿山顶 Puʻu Wekiu 附近（19.8207°N / 204.5319°E，海拔约 4207 m）。在该纬度上：

| 量 | 数值 | 说明 |
| --- | --- | --- |
| 月亮中天高度（交点周期粗扫最高） | 89.7°（6h 步长） | 赤纬过 +19.8° 时恰好过顶，每月两次近天顶 |
| 月亮中天高度（大摆动夏季细扫最低） | 40.7°（20min 步长，2025-06 至 2025-09） | δ = −28.6° 时 90−\|19.8−(−28.6)\| ≈ 41.6° |
| 满月中天高度（2025—2027，37 次） | 41.7° — 88.0° | 过 84° 的满月：2025-02-11、2025-11-05、2026-02-01、2026-11-24、2027-11-13 |
| 月亮视直径（2026—2027，顶心视角） | 28.94′ — 34.07′ | 近地点天顶月比地心值更大（观察者在地表朝月亮一侧） |

默认资料时刻取 2026 年中秋满月窗口 `2026-09-27T05:30Z`（夏威夷当地 9 月 26 日 19:30）：
月亮高度 15.1°、方位 87.7°、视直径 31.8′、亮度比例 99.5%，太阳高度 −18.7°。
初始朝向 88°（正东略偏北）即月出方向。

`scripts/build-ground-audit` 为该落点新增月亮独立样本（`extraTargets`，出自 DE440s）；
太阳与月亮方向差 2.6′—14.3′，来自两个地球定向实现的框架自转相位差，说明见
[地表科学校核](../../solar-system/GROUND_AUDIT.md)。
