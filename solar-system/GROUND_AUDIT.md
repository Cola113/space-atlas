# 九个落点的科学与绘制校核

2026-09-14。这里记录已取得的证据与限制；完整项目的性能、全站交互与发布验收仍在进行。

## 独立参考

`scripts/build-ground-audit.mjs` / `.py` 生成 359 个样本。九个落点均含 1900 年起点、年末、1971、J2000、2100 年末及多个轨道周期。太阳和主星位置来自 [DE440s](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp)、原始 SAT441/URA184/PLU060 记录，以及 [Horizons](https://ssd-api.jpl.nasa.gov/doc/horizons.html) 返回的木卫一、木卫二、木星几何 ICRF 向量。每个木星系统目标包含 71 个独立历元。

CSPICE 独立计算 [PCK00011](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc) 姿态、球面观察位置、局部东/天顶/北坐标及相位。参考与应用均未加光行时、像差和折射；这核验几何模型而非望远镜同期视位置。火星以系统质心代替中心，卫星造成的中心差小于 0.2 m。输入 TT/TDB 使用另有测试的时间层；未来闰秒与早期时间近似没有因此消失。

文件哈希、Horizons 查询及响应头存入 `tests/ground-audit-reference.json`。测试离线运行；原始 SPK、HTML 和完整 API 响应保存在忽略的 `data/` 中。重新生成时 `npx tsx scripts/build-ground-audit.mjs --download` 只下载缺少的 Horizons 查询，较大 SPK 需事先按上述来源准备。

主要行星日心平移继续采用 Astronomy Engine。因而太阳方向与 DE440 仍有差异，不能把卫星相对主星的 1 km 编码要求套用于整个日心模型。木卫一、木卫二、月球的近地表主星方向误差也不能直接以库的地心精度宣传值替代。九落点太阳角直径最大差约 0.258 角秒，主星角直径最大差约 5.25 角秒。

## 遮挡及实际绘制

独立 CSPICE 找到土卫二上 2026-09-13 的一次土星日食出影，并在 14:32:36.536 UTC 附近以九个时刻采样。太阳面采用 131072 条射线与主星球面轮廓相交来估算可见比例，不复用浏览器的圆相交公式。本批最大可见比例差约 0.0440（4.40 个百分点），来自太阳日心模型差等因素；这不是精密接触时刻预报。

运行时遮挡使用均匀亮度圆面、实际距离和角尺度，不含临边昏暗、折射、扁球轮廓或完整土星环透射。多个圆面重叠时对遮挡面积取并集，避免重复扣光。增加火星自身卫星及冥王星其它卫星的天空节点；火卫一、火卫二等仍采用有来源的平均轨道，其凌日不能解读为真实日期预报。太阳、主星及其它球体保持紧凑显示坐标和真实角大小，但每个片元以恢复后的真实视深写入对数深度缓冲；环、云层和太阳光晕共用这套深度。只排序压缩后的球心会把前景小卫星埋进主星显示球体，该问题已用像素测试复现并修正。地形、天体与远方星空分配不同深度区间，地球薄云层仍保留多个 24 位深度级别。

`scripts/verify-ground-rendering.mjs` 使用实际 `SurfaceSky` 材质，针对七个有主星的落点各取三个相位，以 WebGL 像素回读比较独立参考的向阳/背阳区域；另用已知前后关系的物理位置检查太阳前后遮挡、主星前方凌星与后方掩星的中心像素，并检查火星/冥王星卫星节点。这项受控测试采用白色纹理并隐藏地形、大气，以隔离光照与深度问题；不能代替成品纹理、大气及 UI 验收。报告及截图位于 `test-results/ground-rendering/`。成品四屏、浓雾、山体、望远镜、暂停与返回继续由 `scripts/verify-landings.mjs` 检查。
