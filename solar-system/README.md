# 星际图鉴 · Solar Atlas

一个可交互的 Three.js 太阳系网页，包含 58 个可探索天体：太阳、八大行星、五颗矮行星、灶神星，以及 43 颗天然卫星。特殊自转、环、共轨道与资料来源见 [天体模型说明](BODY_MODELS.md)。

## 运行

本场景已并入 Space Atlas。请在仓库根目录运行以下命令，需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

打开终端显示地址下的 `/solar-system/`。生产构建使用 `npm run build`，正式服务使用 `npm start`，预览使用 `npm run preview`。网页需要 HTTP 服务，不能直接双击 HTML 运行。

## 地球卫星云层（第一版）

选中地球后默认进入“卫星观测”，可在云层模式菜单切回“动态模拟”。观测模式采用 [EUMETSAT 全球红外拼接产品](https://user.eumetsat.int/catalogue/EO:EUM:DAT:0330)（CC BY 4.0），不是天气预报或零延迟直播。

- 数据源通常每 3 小时一帧；本地 Node 服务启动时读取缓存并检查更新，之后每小时检查一次，失败后每 15 分钟重试。页面每分钟查询本地状态，手动刷新也合并请求并限频。
- 观测时间来自卫星服务的 WMS 时间维度，表示拼接图的标称时刻，组成它的各卫星像素不保证同时采集。界面以 UTC+8 显示；超过 6 小时标记过期。下载时间不会替代观测时间。
- 服务请求 CRS:84 的经纬度影像，转换为 2048 × 1024 云层纹理。采用红外显示亮度阈值及纬度修正估计云系，**不是正式云掩膜、云量、云高或云厚产品**，对低云、冰雪、冷地表和卫星拼接边界存在误差。
- 南北纬 68°—75°逐渐降低可用覆盖，75°以外不显示观测云；透明和饱和填充值也作为缺测处理。空白不表示晴空。元数据 `coveragePercent` 为有效纹理像素比例，不是全球面积覆盖率。
- 两帧在 3 秒内交接，属于视觉过渡，不推断中间真实天气。暂停时冻结交接并暂存新帧，恢复后显示。实时云层按地理经纬度与地表绑定，不施加模拟风切变、额外旋转、程序化风暴或随机闪电。
- 地球观测时日心时钟使用当前 UTC，地球朝向结合太阳位置与恒星时对齐；暂停时冻结、继续后对齐当前时间。地标观测仍使用相机定位。其它天体自转与卫星绕行由同一模拟日期驱动，轨道与地表共用真实时间倍率；城市夜光仍为 2016 年合成影像。
- 服务端保留最近的不可变云图和原始观测元数据，先保存图片再原子更新指针。浏览器使用 IndexedDB 保存最近成功显示的云图；断网、上游故障和页面刷新后可以恢复。首次无可用数据时不把模拟云伪装成观测云。

场景内实现位于 `server/cloud-service.js`、`src/observed-clouds.js` 和 `src/earth-observation.js`。根目录的 `npm run dev`、`npm run preview` 和 `npm start` 都加载同一个数据服务，缓存保存到根目录的 `data/clouds/`。服务运行期间才会自动检查更新；仅静态托管 `dist/` 时仍需代理云图 API。

根目录的 `npm test` 验证投影、缺测处理、缓存回退、请求合并、过期判断和季节性日照对齐。跨场景及桌面、手机交互通过 `npm run test:browser` 验证。

## 交互

- 点击场景中的星球、名称或底部天体选择栏，镜头在同一场景中连续靠近。58 个天体始终保留实际场景位置；近景中仍可点击远处星体或其名称切换目标，名称遵循球体遮挡。
- 天体图鉴分为太阳与行星、矮行星、小行星，以及各主星的卫星分区。支持中英文名称与所属主星搜索，可叠加类型、系统筛选，并一键清除条件。各分区显示实际匹配数量。打开图鉴时收起底部快捷栏，为目录留出完整空间；选中天体后自动恢复。
- 底部快捷列表可切换太阳与行星、矮行星、小行星或具体卫星系统。选中卫星后只展示同一主星与其卫星；从系统列表切回主星时保留该列表。支持滑动与左右翻页，自动定位并突出所选天体；返回太阳系时恢复太阳与行星列表，刷新保留所浏览的列表。
- 图鉴、底部列表和系统选择菜单采用相同顺序：主星按距太阳由近到远，卫星按实际平均轨道距离由近到远。导航排序不改变场景的更新顺序。无意义的添加顺序编号已移除。
- 场景采用统一的展示比例。行星与卫星的轨道间距以初版的 2 倍为基础，各主星系之间额外预留完整的卫星轨道范围，避免近距交会时互相穿过。全景取景与小行星带同步调整；星体大小和近景取景保持不变。
- 星球上方的系统菜单可切换主星与卫星，或进入地月系、火星系、木星系、土星系、天王星系、海王星系、冥王星系、妊神星系和阋神星系全景。全景中可直接点选卫星，手机上使用精简信息栏给轨道留出空间。
- 鼠标拖动旋转，滚轮继续缩放；触屏支持单指旋转、双指缩放。
- 近距离观测、滚轮和缩放按钮沿当前观察方向平滑移动相机，保持透视视场角与球体尺寸不变；可持续拉远观察周围空间。跨天体移动使用对数距离插值与平滑起停，路径检查避免穿过球体，拖动可中断过渡。
- 地球可切换云层，金星可在云层与雷达地表之间切换。
- 地球支持城市夜光、云层投影开关，以及昼侧与夜侧视角切换；土星支持环系投影开关。
- 地球、火星、木星和冥王星提供可点击的球面地标与选择菜单。定位时自动固定自转，退出地标观测后恢复此前的自转设置；地标观测沿用太阳照明，夜侧地标可能较暗。
- 每个天体都有动态活动，可手动触发、固定自转观察，并单独调节活动速度（0.5 到 4 倍）。
- 支持返回全景、行星图鉴、全局暂停、轨道流速、动态活动及轨道和名称开关、重置视角和全屏。
- Escape 返回，空格暂停，+ / - 缩放。所有主要操作也有可聚焦按钮。

## 动态细节

- 太阳：光球颗粒变化、日珥、局部耀斑和物质喷发粒子。
- 水星：日照方向和晨昏线移动，岩石地表保持稳定。
- 金星：浓云流动和变形，关闭云层后显示稳定的雷达地表。
- 地球：云层聚散、局部旋涡和雷暴闪光。
- 火星：近地尘埃流动，以及扬起、扩散、消散的沙尘暴。
- 木星：差速云带、大红斑周边云纹旋转。
- 土星：大气云流，以及按轨道半径以不同速度运行的环粒。
- 天王星、海王星：各自强度不同的云流与局部云团、风暴变化。
- 木卫一：局部熔岩热点的亮度变化与喷发物散落；热点位置为示意。
- 土卫二：南极附近的水冰喷流，粒子逐渐扩散，可手动增强观察。
- 土卫六：低对比度的雾霾流动与云纹演变，展示大气而非地表。
- 月球、火卫一、木卫二、木卫三、木卫四、海卫一、冥卫一、冥王星、谷神星和灶神星：稳定地形上的日照演示，不将固体地表处理成流动云层。

除地球“卫星观测”云系外，活动采用程序化图形模拟，并非实时观测数据、天气预报或完整的物理求解。时间、空间与亮度经过演示调整；轨道流速和活动速度独立。暂停会同时冻结轨道、自转和动态效果。高细节粒子按需创建，只在当前天体显示；手机减少粒子数量。系统启用“减少动态效果”时，网页默认暂停。

日心方位、卫星位置与镜头跟随均逐帧更新，使用同一模拟时刻；日期文字单独降低更新频率，避免界面更新影响运动连续性。标签布局在移动元素之前集中读取固定界面边界，减少反复触发布局计算。

云流采用两个错开半周期的采样相位，在 24 秒周期内平滑交接，避免纹理随总运行时间被无限拉伸；局部旋涡也限制形变幅度。经度由纹理采样器循环处理，并校正云影经度接缝的采样梯度，避免接缝处出现断续线条。地球云层与云影继续共用同一个密度场。太阳日珥采用带紊流、软边和独立消长的透明条带，替代硬边管状线圈。

## 素材与科学说明

交互场景由太阳位置上的单一点光源照亮，所有行星、卫星、云层及光环按各自相对太阳的方向受光，拖动镜头不改变光照方向。大气辉光也区分昼夜侧；“观测晨昏线”将镜头移动到侧面观察，不再旋转光源。保留少量均匀环境补光以辨认夜侧轮廓。轨道距离为示意比例，因此照明保持展示亮度，没有采用随距离平方衰减的曝光，也没有新增行星之间的食与掩影计算。

背景使用 HYG v4.1 中视星等不超过 6.5 的 8,920 颗亮星；按实际 J2000 赤经、赤纬、视星等和 B-V 色指数呈现，缺少色指数时使用中性色。星点直径限制在约 1.3–1.85 个 CSS 像素，随镜头平移保持远景，不随靠近行星变大，不添加随机闪烁。星空与行星采用相同的模拟日期黄道坐标朝向和场景经度偏转；恒星保留真实纬度，行星既有的展示纬度压缩仍保留，因此不适合精确测量行星与恒星的角距离。未模拟恒星自行、周年视差和变星光变。

银河使用 ESA/Gaia/DPAC 的 Gaia EDR3 银河坐标全天图，通过缩小、滤波、去饱和和压暗，只保留低亮度的大尺度结构；与星表共用坐标变换。明亮天体在画面中占比增加时，背景逐渐变暗，离开后缓慢恢复。这是动态范围的展示近似，不是校准的相机曝光或人眼模型。完整星表暂不可用时保留内置的 96 颗真实亮星；银河图失败不会阻止行星加载。背景不受名称或轨道开关控制。

HYG 数据与派生星表使用 CC BY-SA 4.0；Gaia 图像及派生银河图使用 CC BY-SA 3.0 IGO。来源、上游版本、修改方式与许可见 [星空数据说明](../public/solar-system/sky/README.md)。从整合项目根目录执行 `node scripts/build-solar-sky.mjs` 可重建；网页只加载本地筛选结果，不向外部星表服务发请求。

纹理来自 [Solar System Scope](https://www.solarsystemscope.com/textures/)，基于 NASA 等航天影像制作，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。原始贴图保存在 `../public/solar-system/textures/`。地球、水星、金星地表和火星按需加载 8K 贴图；太阳、木星、土星的高清原图实际为 4K（保留供应方的 `8k_` 文件名）；天王星、海王星及金星云层为 2K。界面根据实际像素尺寸显示分辨率。显示时有照明、明暗起伏和透明云层等处理。供应方地图存在增强色彩与局部补绘。

资料参考 [NASA Science](https://science.nasa.gov/solar-system/planets/)。八大行星与冥王星的日心方位通过 [Astronomy Engine](https://github.com/cosinekitty/astronomy) 计算。展示比例压缩轨道距离与倾斜幅度，并放大天体，轨道线采用 256 点的示意圆轨道，不能用于精密轨道预报。场景间距由 `src/data.js` 的 `ORBIT_SPACING` 统一控制；资料中的平均半径和平均轨道尺寸仍保留实际物理值，集中于 `src/physical-scale.js`，来源为 [JPL 行星物理参数](https://ssd.jpl.nasa.gov/planets/phys_par.html)、[JPL 卫星物理参数](https://ssd.jpl.nasa.gov/sats/phys_par/)与[卫星平均轨道根数](https://ssd.jpl.nasa.gov/sats/elem/)。

动态模拟模式的公转和自转由模拟日期驱动，活动仍采用演示速度。轨道与地表共用模拟日期，初始为 1971-08-01 17:00 UTC；地表推进、暂停和回到着陆时刻会立即同步轨道日期。旧时间线进度一次性重置到新起点，之后刷新恢复已保存的日期。真实时间倍率滑块共 5 档：500×、1k×、5k×、20k×、100k×，默认 1k×，即现实每秒推进模拟 16 分 40 秒；降落和返回均保留选中的倍率。旧单位或不再支持的缓存倍率重置为 1k×，有效档位可随观测状态恢复。地球卫星观测模式使用当前时间与近实时红外云系，仍不属于完整天气或物理模拟。大气厚度、喷流、补光与环系细节经过视觉调整。近景为贴图球面，并非可登陆的三维地形；气态与冰巨行星展示大气，金星地表为雷达着色示意。

八颗有地表资料的天体采用选定区域保护：先把原图重采样到输出尺寸，在最后一步逐像素恢复审核过的保护区。保护区最大通道差为 0，高清 WebP 解码也与加工后的 PNG 完全一致；全景缩略图使用有损编码。遮罩是视觉编辑选择，不是完整的科学覆盖图。缺测和低细节区域的 AI 补绘、修缝与极点处理不代表新获得的观测；原图自带模糊和照明在保护区内仍会保留。土卫六整张为雾霾外观示意，不主张地表观测保护。来源摘要、像素校验及每张处理范围见 [加工说明](../public/solar-system/textures/completed/README.md) 和 [机器记录](../public/solar-system/textures/completed/provenance.json)。

谷神星与灶神星用各自周期的倾斜圆轨道演示，不代表精确方位。卫星公转和行星自转由右下角同一模拟日期驱动；轨道与地表共用当前倍率，1× 为真实时间。海卫一和土卫九保持逆行；独立自转、翻滚与同步朝向按天体分别处理，“固定自转”优先锁定当前观察对象的全部自转轴。冥王星与冥卫一围绕示意质心共同运动并互相同面相向，四颗小卫星绕共同质心运行。妊神星拥有窄环和两颗卫星，土卫十与土卫十一呈现约四年一次的内外轨道交换。形状与运动近似的适用范围见 [天体模型说明](BODY_MODELS.md)。

2026-09-12 另有 28 张完整的 3840 × 1920 艺术重绘贴图，替换低质量或残缺表面；参见 [贴图接入记录](TEXTURE_IMPORTS.md)。三颗新卫星复用现有冰质艺术贴图，界面明确标为地表示意。后续生成提示、球面处理和浏览器验收见本项目的 [贴图工作流程](TEXTURE_WORKFLOW.md)，通用生图 skill 仅提供接口用法。

地球夜光使用 [NASA Earth Observatory / Black Marble](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/) 的 2016 年全球合成图，原始 3600 × 1800 JPEG 保存为 `../public/solar-system/textures/earth_night_2016.jpg`。夜光只在背光区域显现，亮度经过展示调整，不能用于判断当前城市照明。地球云影与可见动态云层使用同一个密度场；投影考虑太阳方向以及地表与云层的相对旋转。土星环与球体使用解析几何计算相互遮挡，环粒也遵循球体遮挡。两者都属于图形近似，并非完整的光传输计算。

土星投影的半影宽度依据当前场景中太阳的半径和距离计算；太阳尺寸经过展示调整，半影也相应变化。环投向球面的阴影对太阳圆面作分条采样，并按像素覆盖范围过滤环的透明度，缓解薄暗带的锯齿。星环的直接散射光参与遮挡，环境补光单独保留，避免整段环纹被硬切成黑块。这些散射与补光强度仍为展示近似，未计算完整的多次散射。

火星地标坐标来自 [IAU / USGS 行星地名录](https://planetarynames.wr.usgs.gov/)，采用东经与行星中心纬度，并换算为贴图坐标。奥林帕斯山、水手号峡谷及其他地标的资料入口保留在界面中。木星大红斑定位对应当前贴图，不能作为实时经度；目前没有加入局部高程网格。
