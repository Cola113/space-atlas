# 猎户座星云

作为星际图鉴第三个独立场景，通过 `/orion-nebula/` 访问。仅自动巡游，保留暂停与继续、曝光与星光调整、画质切换和 PNG 截图。

## 移动方式

约 96 秒的循环路线依次展示全景、中央恒星群、暗尘埃带、发光云壁、外围云带与全景回望。末段适度拉远并回到中央构图，随后连续接回开场，让星云主体保持醒目。相机位置和注视点沿闭合平滑曲线移动，只在正面附近小角度移动，避开细节尚不充分的内部、侧面与背面。手机自动拉远构图。没有拖动、滚轮、双指缩放、键盘移动、观察点跳转或视角选择；暂停后也不能手动改变镜头。

## 影像与深度

素材是 [NASA/ESA Hubble heic0601a](https://esahubble.org/images/heic0601a/) 的 4000 × 4000 出版版 JPEG，观测采集于 2004–2005 年。完整署名：

NASA, ESA, M. Robberto (Space Telescope Science Institute/ESA) and the Hubble Space Telescope Orion Treasury Project Team

采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，遵循 [ESA/Hubble 素材使用说明](https://esahubble.org/copyright/)。署名显示在场景底部，并写入导出图片。原图信息弹层也可查看。本版未调用 AI 生图。

从观测图派生 2048 × 2048 资料图、1536 × 1536 云气参考图、320 × 320 密度参考图和 307 个亮星候选点。云气参考图只对紧凑亮星区域进行局部中值替换，保留云气的细丝与暗带；原有弥散图与模糊细节图保留在素材目录，但当前场景不加载。

初始正面投影以观测影像约束轮廓、密度和颜色。弯曲云壁分布在前后不同深度，影像细节通过有厚度的发光层参与体积积分；斜视和近距离时逐渐降低高频细节，减少投影拉伸。外围增加分离云结、连接云带和稀薄前景，恒星分为远景、区域和云内三个深度层。外围延伸、深度、恒星距离、内部与背面、曝光与照明属于艺术化示意，不是完整实测地图，也不是肉眼或实时观测画面。未把示意云结标注为额外天体。

Web Worker 解码密度参考图，建立 160 × 128 × 144 四通道三维密度场，分别记录气体、暗尘埃、主云体占比和影像亮度。需要 WebGL2、OffscreenCanvas 与 createImageBitmap。射线步进积分连续体积，三维噪声增加局部密度起伏。主云体受正面影像投影约束，侧面不是独立观测数据，也没有把整幅图片作为可见平面放入场景。

恒星使用独立三维点粒子，顶点着色器沿观察射线积分同一体积的消光，抑制被云气遮挡的星光。云气不做快速演化，动态来自相机位移和视差。当前不提供红外切换。

## 构建素材

从仓库根目录运行 node scripts/build-orion-assets.mjs，可下载并重建素材；也可传入已下载的 heic0601a.jpg 路径。source.json 记录原图哈希与加工方式，原始下载无需提交。

## 生命周期和画质

独立 HTML/Vite 入口，仅打开场景时加载。使用平台导航和 sessionStorage 保存巡游时间、播放状态及设置；旧版自由镜头不会恢复。页面离开时释放纹理、工作线程和 GPU 资源。隐藏页面停止渲染，恢复时重置帧间隔；暂停巡游后仅在尺寸、设置或截图变化时重绘。失去 WebGL 上下文后等待恢复并重建页面。系统启用减少动态效果时，巡游速度降低至 40%，也可手动暂停。

| 手动档位 | 像素上限 | DPR 上限 | 体积/恒星遮光采样 | 程序背景星 |
| --- | ---: | ---: | ---: | ---: |
| 精细 | 1,250,000 | 1.10 | 176 / 48 | 8,000 |
| 节能 | 480,000 | 0.85 | 96 / 48 | 8,000 |
| 流畅 | 240,000 | 0.65 | 48 / 16 | 3,000 |
| 极简 | 100,000 | 0.50 | 24 / 8 | 1,000 |

四档共用同一云场、参考图、噪声纹理及星点缓冲；通过统一参数和绘制范围切换，不重建云体或改变巡游位置、速度、曝光。观测亮星候选点、核心示意星群全部保留；两档较低画质减少噪声层次，极简关闭额外体积自阴影，仍积分云气与恒星视线消光。低采样画面可能出现更多颗粒，不能理解为更高精度的观测。

自动挡在所有屏幕上从节能起步，以一秒窗口累计帧耗时。连续两秒低于50 FPS，或单秒低于25 FPS，降一档；连续20秒达到58 FPS后试升一档。试升的三个采样秒内任一秒不足55 FPS即退回，并禁止试升60秒。最低档保持并显示实际帧率；手动档固定。加载、切档、尺寸改变、截图及后台恢复后排除1.2秒预热，暂停不计入采样。刷新恢复用户选择，自动模式重新测量。

画质入口与暂停、截图放在直接可见的工具栏，设置及资料保留文字；全屏位于设置面板。短横屏面板可滚动，Escape关闭后回到打开面板的按钮。

验证：`npm test`、`npm run build`、设置 `ATLAS_URL` 后 `npm run test:browser`。巡游专项为 `scripts/verify-orion.mjs`，四档/按需绘制/高DPI/安全区/键盘/截图为 `scripts/verify-orion-quality.mjs`。`scripts/verify-orion-lifecycle.mjs` 覆盖生产自动降档、恢复、试升失败与冷却；`scripts/verify-orion-native-background.mjs` 使用原生 Edge 标签切换和最小化验证后台行为。`scripts/measure-orion.mjs` 已记录 RTX 2080 Ti 上四档完整绘制与像素回读开销，不将其倒数当作显示帧率。方法、数值与限制见[性能验收](../PERFORMANCE_VALIDATION.md)。
