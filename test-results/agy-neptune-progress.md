# 海王星大气动效优化进度记录 (agy-neptune-progress.md)

## 0. 任务背景与基线数据
- **任务目标**：解决海王星在手机与默认取景下“有在动，但没什么能跟住的结构”、“观感偏噪点原地翻涌而不是云在走”的问题，提供能被眼睛持续跟住的物理示踪物（tracer），同时杜绝一眼假（噪点闪烁、硬边补丁、木星式浓彩条带）。
- **基线量测**（当前 main 分支，默认取景，2048 贴图，12 帧，间隔 700ms，跨度 8.9 秒）：
  - 首末帧（Frame 0 vs 11）：`meanAbsDiff: 3.99`，`pctOver8: 14.3%`，`pctOver20: 4.0%`
  - 相邻帧（Frame 0 vs 1）：`meanAbsDiff: 1.01`，`pctOver8: 1.6%`，`pctOver20: 0.6%`
  - 分析：相邻帧仅 1.6% 发生微小变化，且缺少结构化方向性位移，导致人眼无法建立跟踪。

## 1. 方案发散与评估 (≥3 个切入角度)

### 角度一：旅行者 2 号经典大暗斑系统 + 伴生卷云 + 超速 Scooter 示踪物
- **画面**：用户点开海王星盯 5 秒，在南半球约 22°S 能看到一颗深蓝灰色的大暗斑（GDS），其赤道侧（北缘）紧贴着一簇极高反照率的亮白/微青甲烷冰羽状卷云。在约 42°S 有一团更小的高速不规则白斑（Scooter）。5 秒内，暗斑随逆行急流稳定平移 10–15 像素，伴生卷云在边缘被急流剪切拉长，而 Scooter 以 1.4 倍超车速度向前飞驰约 20 像素。眼睛能极其明确地跟住这两处高对比度亮白结构。
- **评价**：最符合旅行者历史经典印象，双速（暗斑 vs Scooter）带来极佳的层次差与可跟踪性。

### 角度二：哈勃 OPAL / Keck 现代中纬离散羽状卷云带与急流差分剪切
- **画面**：用户点开海王星盯 5 秒，南北纬 30°–45° 分布着数条细碎、半透明、拉长的羽状高空甲烷冰晶云絮列（每组 3–4 朵离散白云絮）。赤道以太阳系最快的逆行风（~400–600 m/s）向西飞退，中纬急流则向东顺行穿梭。5 秒内云絮顺着急流平移 15–20 像素，伴随微小涡旋拉伸。
- **评价**：最符合现代哈勃与 Keck 的日常可见光/近红外真实常态，全纬度都有跟踪点，但单个特征对比度略低于 GDS。

### 角度三：特大赤道对流爆发与高空对流羽流消散 (2017 类风暴复合体)
- **画面**：赤道中低纬出现一处明亮致密的深层对流爆发核心，后方随超强赤道急流拖曳着数万公里的锥形羽流尾迹。5 秒内核心向前狂飙 25 像素，尾部向周围扩散。
- **评价**：单点极具冲击力，但属于偶发性事件，且容易像单点粒子发射器而显人工痕迹。

### 最终决策：有机融合方案 1 与方案 2
- 以 **方案 1（GDS + 伴生卷云 + Scooter）** 建立核心高反照率视觉示踪点，提供不可替代的抓眼焦点；
- 融合 **方案 2（中纬度离散剪切羽状卷云絮带）** 提供全盘与跨纬度的流动感，使背面自转或不同角度观测时皆有清晰云流；
- 结合 **南极温暖极圈与弱环流（70°–90°S）**，完整建立立体冰巨星大气层次。
