# 阶段 1：土卫六海面太阳反光 B

分支：codex/titan-glint-20260926。复核基点：df0075f。2026-09-27。

## 交付与数据门槛

采用 NASA/JPL/Caltech/ASI/USGS [PIA17655](https://science.nasa.gov/photojournal/titans-north/) 的 Cassini RADAR 2004—2013 实测液体假彩色图。不是手画轮廓。源文件哈希、极射赤面标定、颜色分类、腐蚀与未覆盖区规则见 public/surface/README.md；生成脚本 scripts/build-titan-lakes-mask.py。独立 1024×512 掩膜保留 496 个液体内部像元，故**保守漏检海岸、小湖和有文字的区域**，不宣称是完整海岸线矢量产品。三张既有 Titan 贴图字节及哈希未变。

代码直接共享 physical-lighting 的 body.sunDirection 引用，沿用 JPL SAT441 与 IAU 姿态。只有向阳、朝相机的海域片元且反射错角小于 2°时发光；以 0.35°核心、线性辐亮度系数 12 做视觉增强。GPU 单次掩膜采样，无每帧 CPU 湖图重算；无物理量、落点或目录改动。

## 数值与像素证据

复现：运行 npm run dev -- --port 5192，然后依次执行：

- npx tsx scripts/verify-titan-glint-geometry.mjs
- node scripts/verify-titan-glint-render.mjs

扫描 2014-08-01 至 08-31，每小时一次，固定 Kraken 保守内部点 63.10546875°N / 42.01171875°E，选太阳最高样本。此位置来自测得掩膜的宽内部区域，不是 2009 年 VIMS 原反射点。2014-08-19 14:00 UTC：太阳高度 49.7195017°，视线单位向量（表面指向相机、显示空间）为 [0.28929745, 0.95461545, 0.07082606]；相机距该表面点 4.2 个展示半径。归一化预期强度为 1。

独立数值路径：渲染/单测使用 reflect(-Sun,normal) 与视线点积；参考同时采用解析角平分线及全球 3°格点、连续缩步的反射光线优化。解析与数值法线差 0.00000147878°。完整向量、镜头与扫描记录在 geometry.json。

会话种子提供相机方向；单独测得桌面初始距离 4.86 展示单位、方向误差 0°，而目标距离为 2.85275，因此只靠种子不能复现原画面。脚本断言种子方向，再通过只读 `window.solarAtlas.snapshot()` 观察距离并模拟滚轮输入达到 `cameraOffsetRadii × 0.57` 的目标距离，没有向产品加入写入诊断入口。固定相机相对天体中心的显示向量，逐小时推进；2014-08-20 06:00 UTC 所有掩膜中心强度均为 0，最小错角 4.07774°，太阳高度仍为 48.50947°，说明不是简单夜面关灯。JS/GLSL 使用相同有限支撑响应。

## 边界与未做

5 μm 不等于可见光。Stephan 等 2010（DOI 10.1029/2009GL042312）和 PIA18432 支持镜面现象；可见光浓雾会严重弥散高光，本实现是明确的视觉增强。既有底图是 AI 雾霾示意；当前不是可见光探测影像、完整辐射传输、Cassini 轨迹复原、波浪模型或地表全景。掩膜边界仍受已声明的 JPEG、投影标定与网格近似限制。

暂停不关掉真实几何反光；现有时间倍率驱动日期，建议用 1k×演示及暂停检查。没有新增“何时能看”的产品入口；相机复现逻辑仅在验证脚本中运行。未 push，未改 main 或其它 worktree。
