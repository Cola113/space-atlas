# 完整艺术地表贴图

2026-09-12 使用八方 API 的 `gpt-image-2` 生成，用于替换残缺全球图、低细节色块与近黑色程序纹理。优先考虑完整度、可辨认的地貌和统一的精细度；这些是艺术地表，不是新增的探测影像。

共 28 个天体：天卫五、土卫九、天卫一、天卫二、天卫三、天卫四、土卫七、海卫八、鸟神星、妊神星、阋神星、火卫二、木卫五、木卫十四至十六、木卫六、土卫十、土卫十一、土卫十六、土卫十七、土卫十五、土卫十八、海卫二、冥卫二至五。

## 文件

- `*-3840.webp`：3840 × 1920 原生生成图经球面边缘处理后的无损 WebP，近看时按需加载。没有放大冒充高清。
- `*-1920.webp`：1920 × 960 有损 WebP，用于全景与导航缩略图。
- `provenance.json`：模型、处理范围、源文件及成品哈希、实际尺寸、覆盖和接缝检查结果。

天卫五和土卫九参考原来的 `2k_miranda.jpg`、`2k_phoebe.jpg` 重绘整张地图；原图仍保留在上一级目录，来源与署名参见 [太阳系说明](../../../../solar-system/README.md)。其他 26 张是根据各自的外观特征生成的艺术地表，没有使用原程序纹理作为参考。

经线两边各 3.5% 宽度内做对应地貌的平滑镜像混合，两极各 2.5% 高度内收敛极点颜色。处理后左右边缘像素一致，极点不随经度改变；这些数值检查用于发现映射缺陷，还需配合六向球面视图检查。所有地貌均可重绘，不设置原图像素保护区。

现有加载器保留最多三张高清 GPU 纹理，其他天体恢复全景版本。界面来源标注为“AI 艺术重绘 / 完整地表”。

处理脚本为 `scripts/prepare-artistic-textures.py`，依赖 Pillow、NumPy，只处理已保存图片，不调用生图接口。输入 manifest 使用 `id` 和可选的 `reference` 文件名字段；原始 PNG、提示词和私有请求记录保存在任务交付目录或工作目录，不提交到仓库。
