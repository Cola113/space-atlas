# 4K 贴图补强（AI 放大，非原生分辨率）

2026-09-24 生成并接入。本目录的贴图**不是原生素材，是用 AI 超分放大的**：把项目原有的
2048×1024（土卫一 / 五 / 八 还用到 1024×512 的概览层）放大到 4096×2048 / 2048×1024。
放大出来的细节由模型生成，**没有新增任何实测信息**，不能当观测数据用。

## 起因与范围

逐个核对 `solar-system/src/data.js` 与 `additional-bodies.js` 里每个天体**实际使用**的贴图
（不靠文件名推断），58 个天体里只有 6 个的生效贴图窄于 3840：灶神星、土卫一、土卫五、土卫八、
天王星、海王星。

| 天体 | 改前（生效贴图） | 改后 | 说明 |
| --- | --- | --- | --- |
| 灶神星 | `2k_vesta.jpg` 2048×1024 | `sr4k/vesta-4096.webp` 4096×2048 | 撞击坑地貌，放大收益明确 |
| 土卫一 | `repaired/mimas-1024.webp` + `repaired/mimas-2048.webp` | `sr4k/mimas-2048.webp` + `sr4k/mimas-4096.webp` | 概览层原本只有 1024 宽，落点天空取的就是它 |
| 土卫五 | `repaired/rhea-1024.webp` + `repaired/rhea-2048.webp` | `sr4k/rhea-2048.webp` + `sr4k/rhea-4096.webp` | 同上 |
| 土卫八 | `repaired/iapetus-1024.webp` + `repaired/iapetus-2048.webp` | `sr4k/iapetus-2048.webp` + `sr4k/iapetus-4096.webp` | 同上 |
| 天王星 | `2k_uranus.jpg` 2048×1024 | **不改** | 贴图本身几乎没有可见结构（全图相邻列亮度差 0.00/255），AI 放大只会凭空捏出条带或斑块，违反真实性标准里“给天王星画木星式条带属于反科学”的红线 |
| 海王星 | `2k_neptune.jpg` 2048×1024 | **不改** | 同上（相邻列亮度差 0.26/255），没有可放大的真实结构 |

土卫一 / 五 / 八 顺带说明：同目录里还有 `4k_mimas.jpg`、`4k_rhea.jpg`、`4k_iapetus.jpg`
三张 4096 宽的旧图，但它们的经度接缝是裂的（接缝处亮度差 128 / 57 / 2.7，全图相邻列差约 4–11），
2026-09-15 的修复就是因为这个把它们换成了 `repaired/` 版本。所以**不回头用旧 4K 图**，
而是在接缝已修的 2048 上放大。

## 方法

- 工具：`realesrgan-ncnn-vulkan` v0.2.5.0（Real-ESRGAN 官方 ncnn 版），模型 `realesrgan-x4plus`，
  Vulkan 后端（本机 Intel Arc 核显）。2× 放大，一张 4096 约 2 分钟。
- **经度接缝**：先把源图按 3×3 平铺，再裁出「中间 + 一圈补边」喂给网络，让左右边缘都能看到
  真实邻接内容（补边留黑会让网络把黑角渗进第一块 tile，实测接缝亮度差会从 0.4 涨到 15.5）；
  放大后裁回精确 2:1，再把首末两列取平均——源图本来就是首末两列相等的约定，这样球面接缝不会出现细线。
  注意：用交叉淡入的「羽化带」修接缝反而更糟（实测 34 vs 3.5），所以没用。
- 尺寸：目标宽度 4096（土卫一 / 五 / 八 的概览层为 2048）；放大结果大于目标时用 Lanczos 缩回。
- 编码：WebP quality 92。逐张数据见 [provenance.json](provenance.json)（源/输出 SHA256、尺寸、
  模型、倍数、耗时、接缝与相邻列差）。
- **质量闸门**：每张都要过「非退化」检查（灰度极差 < 8 判失败）。实测这个 exe 大约每 6 次会出现
  一次「退出码 0 但写出全黑图」，脚本内置最多 3 次重试；本轮灶神星确实重试过一次。
- 复现脚本：[`scripts/upscale-equirect-textures.py`](../../../../scripts/upscale-equirect-textures.py)。

## 限制

- AI 放大不增加信息量：只能让屏幕观感更细，不能替代更高分辨率的真实地图，也不是“原生 4K”。
- 冰质卫星的坑洼可能被磨平、或长出细碎的假地貌；这些都不是实测地形。
- 土卫一 / 五 / 八 是在**已经 AI 修复过**的地图上再放大，属于二次生成内容，示意性质比灶神星更强。
- 天王星、海王星维持 2K，理由见上表；这不是遗漏。

来源许可沿用 [太阳系资料说明](../../../../solar-system/README.md)。AI 加工不取消原始素材的署名要求。
