# 补绘贴图来源与限制

本目录为太阳系的九张视觉补绘贴图，生成日期为 2026-09-10。使用八方 API 的 gpt-image-2 图生图，以各天体原始球面地图作为参考；原始地图仍保存在上一级目录。来源和许可沿用 [太阳系资料说明](../../../../solar-system/README.md)，AI 加工不取消原始素材的署名要求。

## 加载版本

- `*-1920.webp`：1920 × 960，全景和导航用有损缩略图。
- `*-3840.webp`：3840 × 1920，观察时按需加载的无损纹理。解码 RGB 与加工 PNG 逐像素一致。
- `provenance.json`：原图文件名和 SHA-256、保护区校验、接缝指标、编辑范围及文件尺寸。没有私有请求、凭据或机器路径。

生成请求为 4096 × 2048，服务实际返回 3840 × 1920。没有把返回结果再次放大成 4096 × 2048；这些尺寸也不代表真实观测分辨率。

| --- | --- | --- |

| 火卫一 | JPL / USGS，`2k_phobos.jpg` | 保留选定原图地貌，补绘低细节区域 |
| 海卫一 | JPL，`2k_triton.jpg` | 保护非黑色影像内部，补全缺测黑区 |
| 土卫六 | JPL / David Seal，`2k_titan.jpg` | 整张为大气雾霾外观示意，没有地表保护区 |

保护区指原图经 Lanczos 重采样后的对应像素，剔除遮罩边缘两个原图像素后，在合成最后一步恢复。八张地表地图的保护区最大通道差均为 0，校验哈希相同。遮罩是经过视觉检查的编辑选择，不是经科学认证的完整影像覆盖图。

经线修缝只在未保护区域进行，使用两侧颜色协调和窄连续过渡；极点统一同一极点的颜色。数字连续性检查与球面外观检查互相补充，不能证明地貌真实。AI 新增地形属于艺术补全；源图原有的模糊、明暗和局部变形在保护区仍可能存在。土卫六表现可见光雾霾，不表现雷达地表。
