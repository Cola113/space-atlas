# 首屏预览与导航缩略图

`scripts/build-solar-previews.mjs` 从当前发布素材生成，保留原素材来源与许可（见太阳系 `TEXTURE_IMPORTS.md` 及各素材目录说明）。这里仅降采样和WebP编码，没有生成新的天体细节或新增观测内容。

首屏11张：太阳、八大行星、土星环、基础地球云层，总计214,978字节（约210 KiB），小于1.5 MiB预算。行星宽768像素，环/云层宽512像素。`manifest.json` 记录原文件、处理后尺寸、字节数与前后SHA-256。

`../thumbnails/` 包含58个天体的192像素宽导航缩略图。高清贴图及地表全景继续独立按需使用；预览不得当成新增高清素材。分阶段加载的运行时接入状态见项目 `IMPLEMENTATION_STATUS.md`。
