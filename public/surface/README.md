# 表面观景素材与坐标

九个固定观景点落地后只允许改变朝向，不移动、不变焦。地面使用透明天空的全景球，天空天体独立绘制，地平线遮挡天空。轨道与地表共用模拟日期与倍率；在地表推进、暂停或回到着陆时刻时，轨道日期立即同步。返回时按这个日期更新轨道天体，保留当前倍率并恢复相对天体的镜头位置。

网页的模拟起点为 1971-08-01 17:00 UTC，与月面资料默认时刻一致。此版本将旧时间线进度一次性重置到这个起点，之后刷新或返回场景会恢复已保存的日期。地球的“卫星观测”模式仍使用当前时间匹配近实时云图。

轨道与地表共用真实时间倍率，两个滑块采用相同的 5 档：500×、1k×、5k×、20k×、100k×（k 为千）。默认 1k×，即现实每秒推进模拟 16 分 40 秒。旧单位或不再支持的缓存倍率重置为 1k×，有效档位可随观测状态恢复。暂停与回到本次着陆时刻仍可用，回到着陆时刻不改变倍率。

月面地球的云层使用独立薄球壳。地表相机近裁剪面设为 10（全景地面半径 100、地球显示距离约 300），提高深度精度，避免云层与球面交替遮挡形成黑线。云层与木星云带采用 72 模拟小时的双相位平滑交接，限制纹理形变，避免历史资料时刻到现代日期之间的累计漂移将纹理拉成细条；天体自转仍由星历时间驱动。

## 降落与返回

纹理准备完成后，约 2.1 秒轨道靠近，遮罩过渡后约 1.3 秒镜头稳定。返回包含约 0.85 秒淡出地面与 1.5 秒轨道拉远。轨道阶段的摄影机真实移动；全景地面不平移，最后一段仅改变焦距与朝向来稳定画面，不宣称拥有高空地形或连续真实下降轨迹。可跳过或取消，减少动态效果偏好下直接切换。加载失败保留返回入口。

页面隐藏时，表面时钟、镜头动画和绘制停止，回到页面不追赶后台经过的时间。暂停时仍可转头、拍照和返回。

## 月球 / 哈德利–亚平宁

- 来源：[LPI Apollo 15 Lunar Module North / JSC2007e045379](https://www.lpi.usra.edu/resources/apollopanoramas/pans/?pan=JSC2007e045379&zoom=True)。原始文件：`https://www.lpi.usra.edu/resources/apollopanoramas/images/print/original/JSC2007e045379.jpg`，13967 × 1850。
- Apollo 15 / NASA，摄影 James Irwin；拼接 Warren Harold，NASA Johnson / LPI。相关帧与场景说明：[Apollo Lunar Surface Journal](https://apollojournals.org/alsj/a15/images15.html)。原始 NASA 航天照片，不主张原始影像版权。
- 发布 `moon.webp`：8192 × 4096，RGBA。保留照片地形、登月舱与车辙，去除与顶部相连的黑色天空；将狭长柱状全景近似转为等距柱状全景，并融合水平接缝。原图没有脚下视野，约 -27° 以下使用照片月壤的色调与颗粒统计，程序合成均匀土壤纹理，再渐变融合与极点平滑。这一区域是程序补绘，不是真实拍摄或测量的地形；不会复制新的车辙。
- 北向和垂直投影近似校准：全景中心朝向约 105°，Mt Hadley 对应东北方。摄影机方向没有完整标定，因此不能将地面某个像素当作精确测量。
- 直接打开场景时的默认资料时刻为 1971-08-01 17:00 UTC；从太阳系降落时会继承当前日期。落点约 26.1322° N / 3.6339° E，眼高 1.65 m。

### 计算方法与限制

Astronomy Engine 2.1.19 的 J2000 赤道系星历，经表面自转坐标转换到落点东、天顶、北坐标。月球使用 `GeoMoon` 与 `RotationAxis`，木星卫星使用 `JupiterMoons`；火星、水星、冥王星使用 `HelioVector` 和 `RotationAxis`。观察者位置包含天体半径及 1.65 m 眼高。未做光行时、像差与大气折射修正。视半径按实际天体半径 / 观察距离计算，没有沿用太阳系放大的展示比例。

土卫六、土卫二、天卫五的 IAU 极轴与自转系数来自 [NAIF pck00011.tpc](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc)，分别按 1221900、238400、129846 km 平均轨道距离沿零经线反向放置，属于同步圆轨道近似，忽略偏心率、轨道进动与摄动。冥卫一按平均间距 19600 km 与冥王星理想互相锁定放置。平均轨道及半径参考 [JPL 卫星平均元素](https://ssd.jpl.nasa.gov/sats/elem/) 与 [物理参数](https://ssd.jpl.nasa.gov/sats/phys_par/)。不用于精密互食预报；IAU 公式以 UTC 代入也未包含完整时标修正。

“前往下一次日照”以不超过约四分之一个当地太阳小时的间隔搜索未来两个太阳日内太阳高度超过 8° 的时刻；不改变流速，日期同步轨道。极夜可能找不到满足条件的时刻，此时提示并保留原时间。主星在地平线下或被泰坦雾霾遮蔽时，望向按钮给出原因；标签也检查全景遮挡。

天体位置在三维天空中压缩绘制距离以避免浮点误差，保留方向和视角大小。太阳和各卫星方向、视大小、恒星的落点坐标转换、地球与木星自转随表面时间更新。主光方向随太阳改变。太阳被地球或木星遮挡时，以平面圆盘重叠近似局部日照衰减；不模拟精密互食、卫星在木星上的影子和地形投影。

地表曝光随太阳高度与遮挡平滑变化，夜间保留微弱展示补光；原片已有的局部阴影保持原样，不能根据全景图恢复真实三维地形和动态投影。无大气天体的太阳柔光是曝光效果。火星、泰坦、冥王星有独立展示大气材质，并非完整辐射传输模型；土卫二喷流和木卫一熔岩变化为艺术动画，随暂停一起冻结。

加速时间会把木星遮挡太阳的过程压缩到不足一秒。地面亮度和星点曝光以约 0.4 秒的响应时间平滑趋近目标，避免短暂遮挡变成突兀的黑闪；太阳位置与遮挡计算仍使用当前模拟时间。暂停时显示曝光一起冻结，回到着陆时刻则立即复位。

天体表面经线纹理对齐为展示近似。地球和木星地图来自 [Solar System Scope](https://www.solarsystemscope.com/textures/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。云层、云带以纬度相关纹理扰动显示缓慢流动，随同一个表面时钟推进和暂停，不是所选时刻的天气观测或气象预测。其它三颗木星大卫星使用灰色球体。

恒星来自 David Nash / HYG v4.1（[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)），保留 J2000 方向，不模拟自行、视差和变星。星点亮度为显示增强，不是人眼或相机曝光模型；详见 [星表来源](../solar-system/sky/README.md)。

手机与纹理尺寸受限设备使用 4096 × 2048 的 `moon-4k.webp`、`mars-4k.webp`，以降低显存占用，其余新增全景宽度为 3840。其余远处行星使用真实视大小的简化灰色球体。土星作为主星时单独绘制赤道平面的环，内外半径 74500 / 136780 km，环纹理为展示贴图，不包含完整自遮挡和散射。
