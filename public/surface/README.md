# 表面观景素材与坐标

九个固定观景点可以改变朝向，并通过 1×、2×、4×、8× 望远镜变焦；不移动观察位置。默认纵向视场 62°，使用相机 zoom 实现倍率，8× 时约 8.6°。界面和照片注明倍率及纵向角尺度，拖动与键盘转向灵敏度随视场缩小。地形放大受原图像素限制，不代表新增细节。地面使用透明天空的全景球，天空天体独立绘制，地平线遮挡天空。轨道与地表共用模拟日期与倍率；在地表推进、暂停或回到着陆时刻时，轨道日期立即同步。返回时按这个日期更新轨道天体，保留当前倍率并恢复相对天体的镜头位置。

网页的模拟起点为 1971-08-01 17:00 UTC，与月面资料默认时刻一致。此版本将旧时间线进度一次性重置到这个起点，之后刷新或返回场景会恢复已保存的日期。地球的“卫星观测”模式仍使用当前时间匹配近实时云图。

轨道与地表共用真实时间倍率，两个滑块采用相同的 5 档：500×、1k×、5k×、20k×、100k×（k 为千）。默认 1k×，即现实每秒推进模拟 16 分 40 秒。旧单位或不再支持的缓存倍率重置为 1k×，有效档位可随观测状态恢复。暂停与回到本次着陆时刻仍可用，回到着陆时刻不改变倍率。

月面地球的云层使用独立薄球壳。地表相机近裁剪面设为 10（全景地面半径 100、地球显示距离约 300），提高深度精度，避免云层与球面交替遮挡形成黑线。云层与木星云带采用 72 模拟小时的双相位平滑交接，限制纹理形变，避免历史资料时刻到现代日期之间的累计漂移将纹理拉成细条；天体自转仍由星历时间驱动。

## 降落与返回

纹理准备完成后，约 2.1 秒轨道靠近，遮罩过渡后约 1.3 秒镜头稳定。返回包含约 0.85 秒淡出地面与 1.5 秒轨道拉远。轨道阶段的摄影机真实移动；全景地面不平移，最后一段仅改变焦距与朝向来稳定画面，不宣称拥有高空地形或连续真实下降轨迹。可跳过或取消，减少动态效果偏好下直接切换。加载失败保留返回入口。

页面隐藏时，表面时钟、镜头动画和绘制停止，回到页面不追赶后台经过的时间。暂停时仍可转头、拍照和返回。

### 计算方法与限制

九个地表共同读取 `solar-system/src/physics/state.js` 的物理状态。该层使用公里、J2000 赤道惯性坐标和统一 TT/TDB 时刻，与展示缩放分开。主要行星、月球及伽利略卫星继续使用 Astronomy Engine 2.1.19；1900—2100 年土卫二/泰坦取 JPL SAT441、米兰达取 URA184，冥王星—冥卫一取 PLU060。土星、天王星的日心平移仍取 Astronomy Engine，卫星相对位置取 JPL；冥王星系统包含相对太阳的质心轨道及两者相对质心的位置。总览和九落点现在读取同一模拟时刻的位置、速度与姿态，再分别进行显示变换。共享状态不意味着消除了模型近似，完整项目仍待最终交互及发布验收。

位置与姿态分别计算。月球保留 Astronomy Engine 的 IAU 周期项，适用的 34 个卫星和小天体姿态系数来自 [NAIF PCK00011](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc)，不以主星方向锁定经线，也不由经线反推轨道。未额外加入非刚体物理天平动。观察者位于统一定义半径对应的球面上，使用行星中心纬度、东经和 1.65 m 眼高。目标距离、方向及角直径由观察者位置计算，角直径为 `2 asin(radius / distance)`。半径及类型的唯一定义为 `physics/body-definitions.json`，由 `physical-scale.js` 派生提供；太阳统一采用 NAIF PCK00011 中采用的 695700 km 球面半径。

年份包随站发布，当前观景需要时才加载，并缓存与预取前后一年。范围内缺失必要数据时不会替换成圆轨道：初次降落保留返回与重试，跨年时保持最后可计算的日期，暂停推进，重试成功后不会追赶加载期间的时间，并保留用户暂停意图。寻找日照也会等待候选年份的数据。

范围外明确显示近似说明：从最近的 1900/2101 边界 JPL 位置和速度确定独立的二体椭圆轨道，使用 [DE440 GM](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/gm_de440.tpc) 外推，未延拓摄动或长期进动，误差随时间增长且没有精度保证。姿态继续独立外推。边界记录与来源哈希在 `physics/kepler-anchors.json`，由 `scripts/build-kepler-anchors.mjs` 可重建。

1972 年后按已知闰秒转 TT/TDB，未知未来闰秒沿用最后已知值；更早日期按 UT 及 ΔT 近似处理。UT1 以 UTC 近似。未做光行时、像差或大气折射修正，不能用于精密事件预报。照明方向取各天体物理日心位置，观察者位置用于地平太阳方向；曝光、简化材质与固定全景局部阴影仍有展示近似。

“前往下一次日照”以不超过约四分之一个当地太阳小时的间隔搜索未来两个太阳日内太阳高度超过 8° 的时刻；不改变流速，日期同步轨道。极夜可能找不到满足条件的时刻，此时提示并保留原时间。主星在地平线下或被泰坦雾霾遮蔽时，望向按钮给出原因；标签也检查全景遮挡。

天体网格使用压缩绘制距离以避免浮点误差，保留物理方向和视角大小；每个天体片元按真实相机空间距离写入独立深度区间，保证太阳、主星、卫星与环的前后遮挡。地形在天体之前，背景恒星在天体之后，不能仅按压缩后的球心远近判断。太阳和各卫星方向、视大小、恒星的落点坐标转换、地球与木星自转随表面时间更新。主光方向随太阳改变。所有位于太阳前方且覆盖太阳圆面的已计算天体参与局部日照衰减；单个遮挡用圆盘重叠，多重遮挡取圆盘并集。太阳采用均匀面亮度，未建模临边昏暗；不模拟卫星在主星表面的投影或全景地形的实时投影。

地表曝光随太阳高度与遮挡平滑变化，夜间保留微弱展示补光；原片已有的局部阴影保持原样，不能根据全景图恢复真实三维地形和动态投影。无大气天体的太阳柔光是曝光效果。火星、泰坦、冥王星有独立展示大气材质，并非完整辐射传输模型；土卫二喷流和木卫一熔岩变化为艺术动画，随暂停一起冻结。

加速时间会把木星遮挡太阳的过程压缩到不足一秒。地面亮度和星点曝光以约 0.4 秒的响应时间平滑趋近目标，避免短暂遮挡变成突兀的黑闪；太阳位置与遮挡计算仍使用当前模拟时间。暂停时显示曝光一起冻结，回到着陆时刻则立即复位。

天体表面经线纹理对齐为展示近似。地球和木星地图来自 [Solar System Scope](https://www.solarsystemscope.com/textures/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。云层、云带以纬度相关纹理扰动显示缓慢流动，随同一个表面时钟推进和暂停，不是所选时刻的天气观测或气象预测。其它三颗木星大卫星使用灰色球体。

手机与纹理尺寸受限设备使用 4096 × 2048 的 `moon-4k.webp`、`mars-4k.webp`，以降低显存占用，其余新增全景宽度为 3840。其余远处行星使用真实视大小的简化灰色球体。土星作为主星时单独绘制赤道平面的环，内外半径 74500 / 136780 km，环纹理为展示贴图，不包含完整自遮挡和散射。

## 本轮计算与交互核验

- 保留阿波罗 15 号两次 EVA 的独立太阳/地球高度与方位表校验；水星三个轨道内太阳角直径约 1.14°—1.73°，两个公转周期对应三个自转周期。
- 新增 156 个土卫二、泰坦、米兰达、冥王星样本，覆盖四个轨道周期及 1900/2100 边界。原始 float64 SPK 多项式由 CSPICE 独立解算相对位置，并由 CSPICE IAU 及独立 ENU 计算地平天空；最大相对位置差约 0.0561 km，方向差约 3.95e-8 rad。时标由另行验证的转换层提供。这些是模型/编码对照，不是对真实落点、轨道解或地形的总误差承诺。
- `scripts/build-surface-reference.mjs` 和 `.py` 可重建参考。jplephem 摘录文件的分段描述时间覆盖过宽，交给 CSPICE 前将未量化的原始系数按实际记录时段重新封装；没有重新拟合轨道。参考与原始来源哈希保存在 `solar-system/tests/surface-reference.json`。
- 另有九落点 359 个 DE440/Horizons/CSPICE 样本、21 组实际材质相位像素及四种物理遮挡关系校核。独立参考、各落点误差与有限摆动范围见发布的 `/solar-system/GROUND_AUDIT.md`；编码小于 1 km 不等于天空方向和食相预测的总误差也满足该界。
- 浏览器报告在 `test-results/landings/` 和 `test-results/surface-ephemeris/`（开发验收文件，不随站发布）。本轮地表按钮使用文字、44px 点击区与 8px 间隔；弹层按工具栏实际高度预留空间并允许内部滚动。全站其它场景按钮仍需继续改造和核验。
