# 本地界面字体

Barlow 来自 The Barlow Project Authors，使用 SIL Open Font License 1.1，完整许可在 `Barlow-OFL.txt`。

来源：[Barlow 作者仓库](https://github.com/jpt/barlow)、[Fontsource 的 Barlow 包](https://www.npmjs.com/package/@fontsource/barlow)。本次复制 `@fontsource/barlow` 5.3.0 中 400、500、600、700 字重的 Latin WOFF2 子集，文件未修改，总计 89,764 字节。下载的包按其 SHA-512 integrity 核验，文件 SHA-256、版本及分发地址记录在 `barlow-manifest.json`。

这些字体随站发布。CSS 使用 `font-display: swap`，未加载完成时立即使用系统字体，中文使用系统中文字体；移除了会阻塞场景脚本的外部 Google Fonts CSS 导入。
